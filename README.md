# 🚗 8891 中古車爬蟲系統 (Tkinter 視覺化強化版)

本專案已全面升級為 **Tkinter 桌面圖形介面 (GUI)** 版本，針對原命令列（CLI）爬蟲進行了深度的**輸入與輸出優化**，具備多執行緒防凍結、Chrome 實例複用高效採集、即時資料列表展示、本地快速篩選以及 SQLite / CSV 雙格式儲存匯出。

---

## 🌟 核心優化項目

### 1. 📥 輸入優化 (Input Enhancements)
- **彈性頁碼設定**：不再限制只能從第 1 頁開始，可自由設定「起始頁碼」與「結束頁碼」（支援微調控制項 Spinbox）。
- **全站最大頁碼自動偵測**：軟體啟動時自動於背景查詢 8891 全站最新最大頁數，提供「🔍 偵測最大頁數」與「⚡ 填入全站最大頁」按鈕。
- **快速範本按鈕**：提供「前 1 頁 (測試)」、「前 3 頁」、「前 5 頁」等快速鍵，一鍵配置。
- **防呆與輸入驗證**：自動驗證整數格式、結束頁大於起始頁，避免誤輸入引發崩潰。
- **爬蟲參數自訂**：
  - **無頭模式 (Headless)**：預設背景靜音執行，取消勾選即可觀看瀏覽器操作畫面。
  - **間隔延遲 (Delay)**：可自訂頁面抓取間隔秒數（預設 1.5 秒），兼顧爬取效率與網站防護。
  - **資料庫與資料表自訂**：可設定輸出檔名（預設 `auto8891.db`）與表名（預設 `car`），支援「覆蓋 (replace)」或「追加 (append)」模式。
- **任務中斷控制**：支援「⏹ 停止採集」按鈕，隨時可安全中斷爬取並保留已下載的車輛資料。

---

### 2. 📤 輸出優化 (Output Enhancements)
- **即時數據預覽表格 (Treeview)**：
  - 爬蟲採集過程中，**每完成一頁即時串流顯示新車輛**，無須等待全部爬完。
  - 完整呈現：`#序號`、`縣市`、`車輛標題`、`年份`、`里程`、`價格`、`車輛連結`。
  - **互動功能**：
    - **雙擊任一行**：直接於系統預設瀏覽器中開啟該車輛 8891 網址！
    - **右鍵選單**：支援「在瀏覽器中開啟」、「複製車輛連結」、「複製車輛標題」。
- **本地即時關鍵字搜尋**：
  - 表格上方提供搜尋框，輸入縣市或關鍵字（如 `Altis`、`Benz`、`2022`）即時篩選顯示，無須重新爬取。
- **即時數據儀表板**：
  - 即時計算並顯示「總筆數」、「平均車價 (萬)」、「最低價 ~ 最高價區間」。
- **詳細執行日誌 (Console Log)**：
  - 專屬 Log 分頁，以彩色標籤輸出時間戳記與執行動態（INFO、SUCCESS、WARN、ERROR）。
  - 支援日誌一鍵清空。
- **進度指示與多元匯出**：
  - 底部即時顯示 `ttk.Progressbar` 爬取進度條與狀態提示。
  - **SQLite 自動儲存**：爬取結束自動入庫。
  - **一鍵 CSV 匯出**：採用標準 `utf-8-sig`（帶 BOM），在 Windows Excel 開啟完全不亂碼。

---

### 3. ⚡ 效能與架構優化
- **單一 WebDriver 實例複用**：解決原程式每一頁重新開關 Chrome 的 3~5 秒巨大耗時，效率大幅提升。
- **多執行緒（Threading）**：爬蟲工作在獨立執行緒運作，介面流暢滑順不卡死（No Not Responding）。

---

## 🚀 啟動方式

在終端機或 PowerShell 中執行：

```powershell
python auto8891_crawler.py
```
